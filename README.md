## 🛠️ Installation Guide

### 🌐 Chrome, Brave, Edge, and Opera
Installing **CleanText** is quick and simple. No terminal commands required!</br>
Before installing, ensure your browser is in **Developer Mode**:
1. Open your browser's extensions page (`chrome://extensions` or `edge://extensions`).
2. Toggle **Developer mode** on (usually located in the top-right corner).

### 🚀 Setup Steps
1. **Download** the latest `CleanText.zip` file from the [Releases](https://github.com/EmirTheBest7/CleanText/releases/) page.
2. **Extract** the ZIP file to a convenient location on your computer.
3. **Drag and drop** the extracted folder directly anywhere onto your browser's extensions page.
